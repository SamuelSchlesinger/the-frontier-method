# Sources and provenance

[Index](index.md) · [Synthesis](synthesis.md)

All OpenAI manuscripts below are credited to OpenAI, as requested by their
individual README citation blocks. We inspected the pinned TeX and selected
formal statements; this bibliography does not certify the claimed solutions.
The local paper credits Samuel Schlesinger and Ryan Williams, with the weighted
peeling argument credited to Sam McGuire in its acknowledgments.

Repository sources use immutable Git commit URLs. No independent Wayback snapshot
was obtained. For the selected source material, [snapshot.json](data/snapshot.json)
records file hashes, metadata, and the upstream build status. External antecedents
use DOI or versioned/author-hosted primary sources. Access date: 2026-10-06.
